# Norme bibliographique Vancouver (référence rapide)

La norme **Vancouver** est le standard en sciences médicales et pharmaceutiques.
Principe : les références sont **numérotées dans l'ordre d'apparition** dans le
texte, et la liste bibliographique suit ce même ordre numérique (et non
alphabétique).

> ⚠️ Ne jamais inventer ni deviner une donnée bibliographique (DOI, pages, année,
> volume). Si une information manque, la **signaler à l'auteur** pour vérification
> sur la source réelle.

## Appels de citation dans le texte

- Numéro entre parenthèses ou en exposant, selon le gabarit de l'UFR : `...effet
  démontré (1).` ou `...effet démontré¹.`
- Plusieurs sources : `(1,2,5)` ou plage `(3–6)`.
- Le numéro est attribué à la **première** apparition et réutilisé ensuite.
- L'appel se place généralement **avant** le point final.

## Format de la liste des références

### Article de revue
Ordre : Auteurs. Titre de l'article. Titre abrégé du journal. Année;Volume(Numéro):Pages.

> 1. Nom AB, Nom CD, Nom EF. Titre de l'article en minuscules. J Abrév Titre.
>    2021;45(3):123-130.

- **Auteurs** : « Nom Initiales », séparés par des virgules. **Jusqu'à 6 auteurs**
  ; au-delà, citer les 6 premiers suivis de « et al. ».
- **Titre du journal** : abrégé selon les abréviations normalisées (NLM / PubMed).
- Pas de gras ni d'italique imposés ; ponctuation stricte (`;`, `(`, `)`, `:`).

### Ouvrage
> 2. Nom AB, Nom CD. Titre de l'ouvrage. Édition. Ville : Éditeur ; Année. Nombre
>    de pages.

### Chapitre d'ouvrage
> 3. Nom AB. Titre du chapitre. In : Nom CD, éditeur. Titre de l'ouvrage. Ville :
>    Éditeur ; Année. p. 45-60.

### Thèse / mémoire
> 4. Nom AB. Titre de la thèse [thèse d'exercice]. Ville : Université ; Année.

### Site web / ressource en ligne
> 5. Organisme. Titre de la page [Internet]. Ville : Éditeur ; Année [consulté le
>    JJ mois AAAA]. Disponible sur : URL

- Une ressource en ligne **doit** comporter la **date de consultation** et l'URL.

### Texte réglementaire / recommandation (fréquent en pharmacie)
Citer l'autorité émettrice (HAS, ANSM, EMA, OMS…), le titre exact, l'année, et
l'URL avec date de consultation le cas échéant.

## Contrôles à effectuer lors de l'audit

- [ ] Chaque appel du texte → une référence existante (aucun appel « fantôme »).
- [ ] Chaque référence de la liste → au moins un appel dans le texte (aucune
      référence orpheline).
- [ ] Numérotation continue, sans trou ni doublon, dans l'ordre d'apparition.
- [ ] Ponctuation et champs Vancouver homogènes sur **toute** la liste.
- [ ] Abréviations de journaux normalisées et cohérentes.
- [ ] Sources en ligne : date de consultation + URL présentes.
- [ ] Privilégier les **sources primaires** récentes ; signaler les sources
      obsolètes sur les sujets à évolution rapide (thérapeutique, réglementation).
- [ ] Cohérence avec l'outil de gestion (Zotero / EndNote) si utilisé : vérifier
      que le style de sortie est bien « Vancouver ».
